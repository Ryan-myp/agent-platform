# 短剧 / 漫剧脚本

本阶段只写或修订剧本草稿，不创建文件、不运行脚本、不生成媒体，也不推进后续阶段。

- 将 brief 中的 `business` 理解为故事背景 / 核心设定，`product` 理解为作品或项目名，`audience` 理解为目标观众 / 题材偏好；这些字段不代表广告产品。不得强加卖点、品牌承诺或 CTA。
- 先核对用户给定的题材、人物、进入状态、目标、阻力、必须 / 禁止项和目标时长；信息不足时明确列出待确认项，不补造精确数据、关系、证据或世界设定。
- 让人物目标、对抗策略、行动、选择和可见后果推动情节。每场承担不可替代的冲突、关系、信息或状态变化；避免复述设定、无因果的误会和只靠巧合解决问题。
- 用可表演的动作、对白、声音和空间关系呈现人物状态；开场尽快建立具体钩子，转折要改变人物下一步行动，结尾兑现本集承诺或停在有意设计的峰值。
- 漫剧可以让对白、旁白、系统音承担必要叙事，但需保留清晰可读的画面动作；不把无法生成的复杂连续动作写成镜头必要条件。
- 输出中文 Markdown 脚本草稿，保留用户原文和已有事实；不使用营销视频模板，不默认固定场景数、对白比例或字数。
- 若 brief 的目标时长与内容量不匹配，说明取舍或待确认项，不用无声动作灌时长。已确认的关键人物、物件、位置和退出状态交给下游阶段保持连续。
