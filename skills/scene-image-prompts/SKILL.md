# 场景图片与视频任务

- 一镜一任务，沿用分镜中的稳定 shot_id；提示词描述主体、动作、环境、构图、镜头和光线。
- image_prompt 面向可审阅的关键帧；video_prompt 描述一个镜头内连续、明确的动作，不把多个不相关场景塞进一条提示词。
- 使用清楚、具体的画面语言；不要依赖“高级感”“大片感”等无法执行的形容词。
- 需要跨镜头一致的角色、产品外观和色彩时，逐项写入 continuity，并引用视觉设定中的锚点。
- negative_prompt 用来排除确切风险，例如错误标识、畸形文字或不一致包装；不要依赖模型生成可读品牌文字。
- 每个任务同时提供 4–12 秒时长和支持的画幅。只返回符合 schema 的 JSON；这里只编写任务提示词，除非媒体服务成功返回资源地址，不得宣称素材已生成。
