# 短剧 / 漫剧视觉设定

本阶段把已确认脚本转成下游可引用的视觉事实；不生成图片、不调用媒体服务，也不改写剧情。

- 只记录脚本或用户明确提供的可见事实；对年代、品牌、外观、身份和关系中未说明的细节标为待确认，不猜测。
- 区分身份与变体：角色、地点或道具身份不变时，服装、伤势、时间、天气、开合、持有状态等变化作为有来源的变体记录；镜头瞬态（站位、视线、姿势、机位）留给分镜。
- 按角色 / 造型 / 地点 / 道具组织 Markdown 设定；为每项写简洁识别锚点、已确认状态及其生效范围。只有跨镜不一致会被观众识别的事实才写成连续性锁。
- 对道具记录必要的可见状态和持有人变化；对地点记录可复用的空间锚点。不要将整段剧情或人物心理复制进视觉设定。
- 确保漫剧 / 真人短剧的媒介和画风符合用户选择；若视觉形态尚未确定，标为待确认，不自行将短剧改成漫剧或反之。
- 输出可审阅的中文 Markdown 视觉设定草稿，必要时集中列出待确认问题。不要声称外部资产文件已经创建或参考图已经生成。
