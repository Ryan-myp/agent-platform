# 短剧 / 漫剧分镜

本平台将分镜草稿作为可审阅 Markdown 保存；不要要求写入 `剧集/` 文件或读取项目外文件。媒体提示词和生成任务属于下一阶段。

- 严格依据已确认脚本和视觉设定。每个脚本场景都应有镜头承载；确需省略时说明理由，不增加新剧情或改变用户确认的剧情边界。
- 使用稳定的 `S01`、`S02`…编号，后续镜头任务必须沿用这些编号。每镜写清：剧情职责、对应脚本内容、4–12 秒整数时长建议、景别 / 机位、主体可见动作、起点和终点、对白 / 声音、连续性约束。
- 一镜聚焦一个主要动作或信息变化；镜头时长应允许动作、对白与必要反应被看清。复杂动作按可信的状态边界拆分，不在不同镜头中无故重演已完成动作。
- 交代影响因果的空间关系、出入口、人物相对位置、持物和视线；切镜应带来信息、权力、情绪、空间或节奏变化，不为视觉丰富度添加空镜。
- 记录可见的角色、造型、地点和道具锚点，沿用视觉设定里的锁面；不确定时标注待确认，避免镜头间身份、服装、道具状态或画风漂移。
- 镜头时长合计尽量贴近 brief 目标；不要把单镜拆成超过 12 秒的生成任务。剪辑建议不是已完成的视频，也不要假设系统会自动合并镜头。
- 输出结构清晰的中文 Markdown 分镜草稿，供用户确认后生成镜头任务；不生成图片或视频，不调用供应商。
