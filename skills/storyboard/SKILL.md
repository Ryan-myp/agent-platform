# 分镜规划

以逐镜素材为核心组织计划；不要假设本地会通过 FFmpeg 或其他传统工具自动合并镜头。

- 每个镜头服务于一条脚本信息，不要只为视觉丰富度添加空镜；使用稳定的 S01、S02…编号。
- 明确景别、机位、主体动作、场景、时长和镜头间转场；当前视频模型每镜仅支持 4–12 秒，长内容拆成多个独立镜头。
- 在整张分镜中保持主体、产品外观、服装、场景和光线连续；引用已确认视觉设定，不要每镜重新发明外观。
- 口播与屏幕文字不要互相重复到影响节奏；关键事实需清楚可读。
- 镜头时长总和应与目标时长接近；需要确认的制作假设应单独标注。镜头计划应可单独修改、重生成，并能追溯到脚本信息。
